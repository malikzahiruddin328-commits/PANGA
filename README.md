# Job Search Automation Tool

A personal tool to help find, prioritize, and tailor applications for relevant jobs —
starting with your resume and a short interview, then searching job sources and
drafting tailored application materials for you to review and submit yourself.

## What this is (plain language)

- You give it your resume and answer some follow-up questions once.
- It searches for relevant jobs (starting with USAJOBS.gov, then other sources).
- For any job you pick, it helps draft a tailored resume/cover letter.
- **It never submits an application for you** — you always review and send it yourself.

## How to run it

You don't need to use a terminal for day-to-day use. Once the app is built, you'll
open it by double-clicking a shortcut, and it opens in your regular web browser.

## Your data

Everything in the `data/` folder is private to your machine — your resume, interview
answers, and job history live there. That folder is deliberately excluded from
version history (see `.gitignore`) and is never sent anywhere.
